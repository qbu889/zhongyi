### 执行期另外三个技术性改判（不占 R 编号）

- **D1**（`5a6853f`）：Vitest 5 会把 `beforeEach` 的**返回值**当作 teardown 回调并零参调用，brief 里 `beforeEach(() => mockedStream.mockReset())` 因此会在每个用例后被再次调用 mock → 改为块体 `{ mockedStream.mockReset(); }`，断言不受影响。
- **`onUnhandledFrame` 不是笔误**（终审曾怀疑，经查 `node_modules/msw/lib/_chunks/shared-options.d.ts:15` 确认 msw 3.0.3 的选项名确实如此），保持原样。
- **React 重复 key**（`59ee1b1`）：一轮里同一 `ref` 可能有多条 citation（医案链 + 检索命中的 `case:11`），`RetrievalProgress` 用 `ref_type:ref_id` 作 key 在真实浏览器控制台报错——这是 Playwright 抓出的、jsdom 结构上不可能发现的产品缺陷。
