# 辨证论治（六经框架）

基于本地框架做"经定位 → 病性判定 → 定制定方"。诊断必须落地到本地方剂，**不套用通用中医模板**。

## 数据来源
- `distilled/02-伤寒论/六经辨证框架.md` — 定经、传变规律、治则七法（纲领："观其脉证，知犯何逆，随证治之"）。
- `distilled/02-伤寒论/临证诊断与治则补充.md` — 七条正常基准、六诊法、治则七法。
- 方剂落地：`distilled/03-金匮/金匮方剂库.md`、`distilled/02-伤寒论/伤寒六经方库.md`、`distilled/方剂库-经典配方.md`。
- 医案参照：`distilled/06-医案/临床问答对.md`。

## 第一步：立基准（问诊对照表）
`临证诊断与治则补充.md` 七条"正常人"基准，**过与不及皆为病象**，逐项问诊对照：
1. 额凉、手足温（一日四时）
2. 胃口好、饮食能自制、食之有味
3. 容易入眠、能通宵；汗出正常；体表冬暖夏凉
4. 大便每日晨起一行
5. 小便淡黄、一天5–7次；睡时不小便
6. 白天精神好、体力足
7. 脉一息四五至、和缓有力（春弦夏洪秋浮冬沉；寸>尺；男右>左、女反之）

## 第二步：六诊 + 四步辨证
- **六诊**：望（形神气血、五行定位、色位生克）、问（十问为常法）、脉（浮沉迟数、中空结代）、触（皮温/背俞经穴反应点/腹诊/耳诊）、眼（倪氏独门看五脏虚实）、辨阴阳。
- **四步**：①定经（太阳→阳明/少阳/太阴/少阴/厥阴）→ ②定病性（寒热虚实）→ ③定法（治则七法）→ ④定方 + 随证治之。

## 第三步：症状 → 本地方（关键鉴别点）
把每个症状映射到**本地方证**（出处到篇/条/医案号），例如：
- 喘"冬重夏轻"＝**小青龙汤**（寒喘，`伤寒六经方库.md` 第25条）。
- "咳痰白、不能平躺"＝**射干麻黄汤＋桔梗**（肺中湿热兼积水，医案问11）。
- "肺中积水、不能平躺、西医束手"＝**十枣汤**（医案问13）。
- "咳嗽且胃口好坏"＝辨**麻杏甘石汤 vs 大青龙汤**（`伤寒六经方库.md` 第108条）。
- 舌苔白＝射干麻黄汤（方45）；舌苔黄厚＝皂荚丸（方44）。

## 硬规则
- 证型、治则、方、穴**必须引用本地来源**；通用六经/八纲逻辑只能"组织"本地发现，不能替代本地条文。
- 不臆造剂量；古制须按 `formula-lookup` skill 换算成克。
- 结尾须附标准免责声明（执业中医师面诊）。

## 输出格式（对齐 `06-医案/临床问答对.md`）
**问**（主诉脉舌）→ **答**（病机，逐条对应本地条文/基准）→ **治**（经方 + 出处）→ **要诀/调护**（仅列库内穴位与法）。
