# 医案生成

按本地 `06-医案/临床问答对.md` 的 house style 生成/整理经方医案。**全部病机、经方、转归必须源自本地库**，不套用通用医案模板。

## 数据来源
- 样例库：`distilled/06-医案/临床问答对.md`（30 例，5 类：重症/癌症、常见经方症等；格式固定）。
- 辨证落地：先调 `syndrome-differentiation` skill（六经框架 + 七条基准）。
- 方剂落地：先调 `formula-lookup` skill（经方 + 克数 + 出处）。
- 取穴：`distilled/05-针灸/*.md`（仅列库内穴位）。

## 标准格式（逐字段对齐样例）
```
### 问N｜<简要证型/病名>
**主诉**：年龄/性别 + 核心症状 + 脉舌/体征（望诊可知的描述）。
**答**：一望而知 / 病机分析——逐条对应本地条文或七条基准，点出所在经与脏腑。
**治**：<经方>（+ 出处篇/条/方#）；治则方向。
**要诀/转归**：预期归经转归、调护、库内穴位。
```
- 字段固定为 `主诉 / 答 / 治`（样例有的加 `要诀`）；**加粗关键病机与方名**。
- "答"要体现倪氏"一望而知/脏腑温度/残渣逆入"等本地表述习惯。

## 生成步骤
1. 收集主诉（症状、脉舌、体征），按七条基准找出"过与不及"处。
2. 定经定方（调 syndrome-differentiation + formula-lookup），方名/剂量须本地可查、剂量转克。
3. 按上格式落笔；转归须基于库内医案的归经逻辑，不杜撰"治愈/根治"等断言。
4. 结尾附标准免责声明（执业中医师面诊；本库为学术蒸馏产物）。

## 硬规则
- 方、药、穴、病机**必须本地 grep 到**；查不到不写。
- 剂量按 `formula-lookup` 转克并留痕。
- **不伪造真实患者**：若用户给的是真实问诊，注明为整理样例；不得编造检验报告/确诊书。
- 若用户确认保存，按 `distilled/06-医案/README`（若有）或追加到 `临床问答对.md` 末尾同类别下，并递增"问N"编号。

## 保存（可选）
追加到新条目后，确认编号连续、同类别归并、表头说明"合计N例"。
