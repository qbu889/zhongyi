# 《伤寒论》六经辨证框架（倪海厦人纪版）

> 依据《内经·热论》六经辨症思路，由张仲景把经方系统化的"唯一门径"。
> 纲领原文节选自本书序言、前言及太阳篇总纲（倪海厦人纪教程简体整理稿）。

## 一、为什么必须学六经辨证

> "伤寒论的六辨症法则，就是进入经方大门的唯一方法……熟于《伤寒论》后，之后
> 再进入金匮时就能很灵活的使用金匮中的经方。"

- **经方 = 峻药**，讲究"一剂就知，二剂已"。必须先用六经辨证锁定病位与病性，
  才敢大剂量、快速使用；否则"无法透彻了解六经辨证法则，自然不敢轻易使用经方"。
- 与**温病派**对照：温病方温和滋阴、少用峻药，吃错也无大反应，故流俗以为"中医
  就是慢、中药是吃下死"。倪氏强调经方与温病是**两种境界**。

## 三、太阳分证（中风 / 伤寒）——辨汗定方

| | 太阳中风 | 太阳伤寒 |
|---|---|---|
| 原文 | "太阳病，发热、汗出、恶风、脉缓者，名为中风。" | "太阳病……必恶寒，体痛、呕逆、脉阴阳俱紧者，名曰伤寒。" |
| 关键鉴别 | **有汗**（病汗）；脉浮缓 → 表虚，素体偏弱 | **无汗**（毛孔被寒闭）；脉阴阳俱紧 → 表实，体质偏盛 |
| 用方思路 | 桂枝汤（解肌和营卫） | 麻黄汤（发汗解表） |

> "临床使用麻黄或桂枝，就是看病人有汗无汗——即中风与伤寒的区分。"

## 四、传变规律（病势进退的标志）

> "太阳受之，脉静者，为不传也；若脉数急者，为传也。"

- **健康态**：正气**顺时针**运行（天人合一，无病）。
- **向内传**（恶化）：太阳 → 阳明则**停**（胃家实，无死证）；
  太阳 → 少阳则可能再入 **太阴 / 少阴 / 厥阴**。
- **脉象定进退**：病久由阳脉（浮、数）转阴脉（沉、涩）→ 病势进；
  原为**阴脉**经治后转**阳脉** → 病势退、快好；太阳证反转为厥阴证 → 医生当自省。

## 六、辨证总诀

> "观其脉证，知犯何逆，随证治之。" —— 全书纲领八字。

辨证步骤（倪氏强调望、闻、问、切并重，不独尊脉）：
1. **定经**（六经定位）：先辨太阳、阳明……在何经。
2. **分阴阳**（八纲）：阳脉/阴脉、表里寒热虚实。
3. **看进退**：脉由急转静→不传；由阴转阳→将愈。
4. **随证治之**：锁定后即按经处方，"不管里面是什么病（肺癌、肝癌），
   就以太阳证来处方用药就对了"。
