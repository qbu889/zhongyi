## 一、正常人七条标准（诊断基准）

> "不知常，焉知病？" 倪氏认为诊断第一步是确立"正常人"的基准。

| # | 正常表现 | 对应脏腑/机能 |
|---|---|---|
| 1 | 一年四季一日四时 **额凉手足温** | 体内能量运行正常，阴阳平衡 |
| 2 | **胃口好**，饮食能自制，食之有味 | 胃气平、脾气充 |
| 3 | **容易入眠、能通宵**；汗出正常；睡时体表冬暖夏凉 | 心肝血足、心气衡、表阳固密 |
| 4 | **大便每日晨起一行** | 肠道功能好 |
| 5 | **小便淡黄，一天5–7次；睡时不小便** | 肾气旺 |
| 6 | 白天精神好、体力足 | 肺气足 |
| 7 | **脉一息四五至，和缓有力**；春弦夏洪秋浮冬沉；寸脉大于尺脉；男右脉大于左、女反之 | 阴平阳秘 |

> 凡此七条，过与不及皆为病象。临床先对照此七条，异常之处即是病根。

## 二、六诊法体系

| 诊法 | 要点 |
|---|---|
| **望诊** | 形神气血、五行定位、色位生克、时色推移。结合周易望色。 |
| **问诊** | 十问为常法，临证细解方知奥妙。 |
| **脉诊** | 识"四时平人之脉"，辨过与不及；知浮沉迟数、中空结代；晓附骨阴实之象。 |
| **触诊** | ①测皮温（额凉、手掌热、重按至骨测骨寒热）；②脊椎背俞经穴反应点（定位肿瘤/结实）；③腹诊（指导经方）；④耳诊。 |
| **眼诊** | 倪氏独门：从眼象几秒内看五脏虚实、病所、邪性。 |
| **辨阴阳** | 诊断最高境界。明阴阳四时变化、气血周天法度。 |

## 三、治则七法（法象天道）

| 治则 | 病机 | 用药方向 |
|---|---|---|
| ①首重阳气，护心 | 心主神、主火，为阳气源头 | 麻桂姜附硫磺等阳药，行阳助阳、临危救逆 |
| ②阴阳谐调，护肠胃 | 阴阳失和；虚阳上浮；表阳不固 | 桂芍等量（一散一收）；龙牡镇浮；炮附固表；参姜枣草护津液 |
| ③上开玄府，下利水道 | 病在表/肌 | 麻桂葛根行阳，汗而解之；苓泽术夏甘淡渗湿，从小便出 |
| ④推陈致新，谷道常通 | 病在腑 | 硝黄枳朴通便去实 |
| ⑤调和枢机，疏利三焦 | 病在三焦水道 | 柴胡剂和解少阳 |
| ⑥祛瘀生新 | 瘀血内停 | 水蛭、䗪虫、桃仁、茜草活血化瘀 |
| ⑦寒热兼施，补泻同用 | 肠胃与厥阴病，寒热错杂 | 桂附吴萸 + 芩连石膏；六味地黄家 + 苓泽丹 |

## 四、治癌五法（阴实理论）

> 肿瘤＝**阳不入阴、阴实已成**：局部温度过低、动能不足，营养与冷水停积，压力升高，津液热能无法灌注。

| # | 法则 | 操作 |
|---|---|---|
| 1 | **断瘤之源** | 停食一切人工高浓度高营养食品（含奶制品），断肿瘤食物来源 |
| 2 | **以阳制阴** | 阳药恢复天然抗病力，如红日当空、阴云自散 |
| 3 | **疏导攻坚** | 甘淡渗利、咸以软坚，攻散积存、排除冷水、降病灶压力 |
| 4 | **活血化瘀** | 久郁/久积/久病必瘀，去瘀生新 |
| 5 | **常顾胃气** | 脾胃为后天生化之本、抗病力源泉；胃气不绝则无性命之忧 |

**处方节奏**：先护心气、壮心肾之阳、强脾胃，守而待天时；至病脏王时速发重剂猛攻，时机一过即收兵。反复拉锯、步步为营。

## 五、药简力专，敢用毒药

- "经方者经典之方，历经两千年印证，一剂知、二剂已。"
- 服药无效非经方之过，是辨证不准或药力未到。
- 处方常仅数味药，但经方之神已在其中。
- 敢用生附子、麻黄、桂枝等峻药，剂量按证情，不避"少火"之说。

## 六、扶阳理论（卢崇汉·火神派补充）

> 《素问·生气通天论》："阳气者，若天与日，失其所则折寿而不彰。"

- **阳者，天日也**：天之运行即阳气之运行；五行即阳气的五种运行状态（生长化收藏）。
- **五脏皆以阳为本**：心无阳则无以主神明，肺无阳则无以主气，肝无阳则无以罢极，肾无阳则无以封藏，脾无阳则无以仓廪。
- **姜附桂为扶阳主药**：不是偏执，而是从"以火立极"的生命层面推出。
- 与倪氏"心为君主、手脚温为平人"之说一脉相承。
