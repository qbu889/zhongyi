# 05-针灸（倪海厦人纪 · 针灸教程）

> 数据源：`text/倪海厦人纪系列之针灸教程.txt`（讲稿体，非表格）。
> 抽取脚本：`scripts/acupoint_extract.py`（锚定标准十四经穴位白名单
> `scripts/acupoint_whitelist.txt` 精确匹配，过滤散文噪声）。

## 产物
| 文档 | 内容 |
|---|---|
| `十二经穴位库.md` | ① 十二经纳天干地支(五行映射)歌 · ② 十二经五蕌穴位总表(井·荣·俞·经·合／原·络·郄·募) · ③ 奇经八脉·任督重点穴 |
| `针灸治症取穴.md` | 按症状(咳/喘/痛/病/风)分组的常用取穴 |

## 抽取方法要点
- **白名单精确匹配**：仅接受《十四经》标准穴名且在原文中实际出现的穴位，
  丢弃讲稿散文（如"俞原经""在脏取"等误配）。
- **角色关联**：以"穴位 + 五腧角色(井荣俞经合原络郄募)"同句共现，
  重建各穴的井荣俞经合／原络郄募归属。
- **取症**：症状关键词(症/病/痛/风/喘…) + 动作词(取/扎/用/针灸)同句内
  白名单穴位，按症状归组。
