## 蒸馏规则与去重
1. **规范**:全角→半角、删"第X页",统一字符。
2. **方剂/药材**:正则 `([一-鿿]{2,8}(汤|丸|散|方))` + 剂量(克枚两钱帖分位)。
3. **去重**:同方名/药名合并,保留首个完整字段。
4. **辨证框架**:从六经总纲条文 + 传变规律原文综合(非单纯方列表)。
5. **五味归类**:依《神农本草经》"气味/主治"归入酸苦甘辛咸 → 五脏。
6. **医案问答**:从叙述体抽取"主诉脉舌 → 辨证病机 → 经方"临床问答样例。

## 使用建议
- **建立框架**:先读 `02-伤寒论/六经辨证框架.md`、`01-内经/核心理论文档.md`。
- **查方**:按经(`02`)或病段(`03-金匮` 二十二篇);剂量见 `方剂库-经典配方.md`。
- **查药**:按性味(`药物按味归类`)或功效(`中药库`)。
- **临证**:参照 `06-医案/临床问答对.md` 的辨证思路。

> ⚠️ 本库为学术蒸馏产物,用于研究与学习;临床用药须由执业中医师辨证施治。
